# Programming Pathshala - Community Landing Page

A sleek, responsive landing page designed to encourage developers to join a coding community focused on consistency and growth.

## ✨ Features
- **Modern Dark UI:** Clean, professional aesthetic using a deep navy and blue color palette.
- **Interactive Join Form:** A user-friendly registration card for new community members.
- **Data Visualization:** A custom CSS-based bar chart demonstrating the power of consistency.
- **Responsive Design:** Optimized for various screen sizes using Flexbox and CSS Grid.
- **Referral System Section:** Integrated "Refer and Earn" UI to boost community growth.

## 🛠️ Tech Stack
- **HTML5:** Semantic structure for SEO and accessibility.
- **CSS3:** Custom styling including:
    - **Flexbox & Grid:** For the 3-column hero layout and photo mosaics.
    - **Custom Illustrations:** Pure CSS-based person and laptop graphics.
    - **Animations:** Hover effects on buttons and navigation links.
